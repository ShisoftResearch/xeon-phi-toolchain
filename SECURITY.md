# Security

Treat the MPSS-era card OS and SDK as legacy software. This project supplies an
experimental compiler/runtime, not a security update for the card OS, firmware
or management controller. Do not expose experimental application services on
untrusted networks by default.

For a suspected vulnerability, contact the repository maintainer through the
hosting provider's private reporting facility if enabled. Do not place secrets
or operational connection details in public issues. No private reporting email
or hosted advisory service has been configured by this source release.
